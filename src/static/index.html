Actions

Redaction mode masks sensitive details — case/receipt numbers, applicant and representative names — everywhere on the site: the Cases, Updates and System tabs, including the raw snapshot JSON and system-log details. It also disables Download full history + Copy this snapshot and grays out every action button (Pull, Debug, Export, Recompute, Clear log) behind a lock — each one then needs the site admin password to actuate. Masking happens on the server, so private data never reaches the browser. Turn it on before screenshotting or screen-sharing; toggling it requires the password.
Access Lock gates the whole dashboard behind the site admin password: while it's on, every visitor is sent to a login page and the API rejects unauthenticated requests, exactly like a password-protected site. Turn it off to make the dashboard open to view again. Flipping it in either direction requires the admin password. Independent of Redaction — Access Lock controls who can see the site; redaction controls what's visible and what can be done once they're in.
Recomputes every diff. Clears cached diffs and forces a fresh chronological diff trace across every case you track, re-walking each case's full snapshot history. A diff_recomputed event with per-case change counts is appended to the log below so you can confirm the data flowed through.
Debug mode forces every pull (success or failure) to preserve its full Playwright trace (trace.zip) plus the mfa_trace/ sidecar with wire-level IMAP events and archived emails. Off, traces are only kept when a pull fails. Use this to verify the capture system against a known-good pull. Disk-heavier — flip back off when done.
Export data
Exports every case. Downloads a single zip containing every data/{form}_case.json (the full per-day snapshot history of each case you track) plus a manifest.json with each case's label, receipt number, and entry count. Each snapshot is the raw USCIS API response — contains applicant info, letter IDs, etc. Treat the file as PII.
